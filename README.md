# Lumina Library - Online Book Borrowing Platform

## Purpose
Digitize the traditional library experience with a modern book borrowing platform. Users can explore a curated catalog, filter by category, and borrow titles securely with BetterAuth.

## Live URL
https://lumina-library-seven.vercel.app

## Key Features
- Authentication with email/password and Google.
- Private routes for Profile and Book Details.
- Book catalog with search and category filters.
- Borrow history with pagination in the Profile page.
- Responsive design for mobile, tablet, and desktop.

## Tech Stack
- Next.js
- Tailwind CSS
- HeroUI
- BetterAuth
- MongoDB
